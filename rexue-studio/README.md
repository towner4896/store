# 热血短剧工作台

Windows 64 位软件，内置在线更新。

[下载 0.5.6 Windows 分享版](https://raw.githubusercontent.com/towner4896/store/master/rexue-studio/windows-x64-0.5.6.zip)

下载后完整解压，双击「热血短剧工作台.exe」。无需安装 Python。首次使用请填写自己的 AI API Key，AI 调用费用由各自账号承担。

以后更新：保存作品 → 右上角「检查更新」→ 下载更新 → 重启安装。更新保留本机小说和项目，朋友之间不会同步小说或密钥。只有发布者发布新版本才会提示更新。

已有 0.5.0 版的用户，可在更新窗口的更新来源中填入以下地址并保存，再检查更新。更早没有更新器的版本需要先安装本分享版。

```
https://raw.githubusercontent.com/towner4896/store/master/rexue-studio/channel.json
```

此处只存放公开程序和更新包，不包含个人小说、API 密钥或使用记录。连接失败时请稍后重试或联系发布者。

## 0.5.2 新增

大纲问答搭档：主动提问和推荐选项，讨论后生成完整大纲草稿，预览确认后应用。支持撤销，已有小说保留并标记复核。

## 0.5.3 新增

AI设置内置「记住密钥」，使用Windows DPAPI加密保存，重启和更新后自动读取。可以清除或取消记住，仅本次使用。密钥位于本机用户账户目录，不在程序、项目备份或分享包中。旧版首次升级后需输入一次并保存。

## 0.5.4 新增

修复创作笔记改回原样仍被判定未保存的问题。下载新版后，可点击「一键保存草稿并更新」，保存当前页面未完成的编辑、未发送聊天、创作笔记、选题意见和本次要求。其他标签页需分别保存。重启后点击「恢复草稿」继续编辑，草稿不会自动提交AI或覆盖正式作品。保存失败不会开始安装。

旧版若一直提示未保存：先保存正文和创作笔记，将未发送的重要文字复制留存，关闭旧页面并重新启动软件，再检查更新。

## 0.5.5 新增

大纲与章节聊天只保留一个发送按钮，Enter发送、Shift+Enter换行，创作笔记与历史默认折叠。AI根据输入判断提问、建议或生成完整草稿。可以直接说「全部按推荐的来」。有草稿时，发送「继续下一步」表示采用这份草稿并开始下一章，一次推进一步；最后一章完成后提示复核完稿。没有草稿时先讨论或整理草稿，不会跳过确认。陈旧草稿仍受保护，不能覆盖新的手动编辑。

## 0.5.6 新增

确认大纲后，在小说章节页选择起止章节，点击「开始批量生成」，按前文连续写作并逐章保存。写作直接输出小说，不逐章提问或等待确认。默认跳过已有有效章节；需要重写时勾选覆盖。可以在当前章完成后停止。达到预算提醒阈值或接口报错会停止后续调用，已完成正文保留，失败章节不自动重试。重新打开项目可找回仍在运行的批次；程序退出后重新开始会跳过已保存章节。批量运行时请保持程序打开。小说页默认展示正文，连续性摘要和修改聊天可展开查看。
